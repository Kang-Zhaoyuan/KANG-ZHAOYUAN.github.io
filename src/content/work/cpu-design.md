## Overview / 项目简介
Course-based CPU development using the miniRV instruction set (an RV32I subset), with processor datapaths, control logic, simulation files, and FPGA project integration.

以 miniRV（RV32I 子集）为基础，设计 CPU 数据通路、控制逻辑与仿真测试，使用 Vivado 管理 FPGA 工程。

## Engineering scope / 工程内容
- RTL modules for ALU, controller, memory access, and CPU datapaths / ALU、控制器、访存和数据通路 RTL
- Vivado simulation workflow and EGO1 FPGA target / Vivado 仿真流程与 EGO1 FPGA 平台
- Separate course-lab collaboration repository / 课程实验协作仓库：[cpu-design-labs](https://github.com/Kang-Zhaoyuan/cpu-design-labs)
